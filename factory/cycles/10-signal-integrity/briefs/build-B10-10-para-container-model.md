# Build #B10-10 — the PARA container model and parameterization

Arc 10's deepest inherited build: the head of A9-1, the filing Arc 9 was originally
named for. Three acts, one boundary:

1. **The container model** — ship the object both field vaults built independently
   because the module didn't (S1: app-vault broke the location rule to get an honest
   in-PARA container; vlt-sayari obeyed it and its container fled to a shadow tree in
   `_agent/projects/`). Charter + running record + register, 2–3 files; a container
   `status:` enum; per-type artifact `status:` enumerated at last, closing the
   `extraction.md:94` angle-bracket placeholder that made three vaults derive three
   incompatible vocabularies (25 distinct values in one vault).
2. **The parameterization** — PARA keys into `vault_structure`, which first requires
   making key-minting safe: `merge-config.py`'s whole-dict preserve means a newly shipped
   structure key never reaches an existing vault's map (the C6-b debt; both shipped
   interim clauses — `full-scale.md:7` and the contract's `:48` zone row — say in so many
   words that key-minting waits on exactly this fix). The same act deletes B10-2's
   interim `crossLayerSlugs` supplement (D2's bound cleanup) and rewrites the
   upgrade-reports no-key clause (its own shipped retirement clause).
3. **The authorship re-draw (C1)** — Layer 3's boundary recast from a location
   impossibility claim ("partners never write into PARA" — while `para_missing_attestation`
   has operated a named net for that "impossible" write since the day it shipped) to an
   authorship-honesty rule, recast across the five recitation sites. `grounding:` ships
   as the missing provenance-edge field, inheriting the personalized-extraction firewall
   checks in the same build (Q7 — enforcement ships with the widening).

All rejected alternatives in the parent filing are settled — do not re-litigate. In
particular: C2 (posture axis), C3's write-time gate (R-a), and the write-verb name were
retired by the filing's own roundtable; K12 (multi-user trust) is owner-ruled out of
scope; the body's "compliance theater" framing is superseded by K11's
missing-edge-not-breach grading (capture's provenance correction) — brief and build text
carry K11's framing only.
